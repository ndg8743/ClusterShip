# ClusterShip

## Prerequisites
- Go 1.22+ installed

## Run
```powershell
go run ./cmd/clustership
```

## Build
```powershell
go build -o bin/clustership ./cmd/clustership
```

## Test
```powershell
go test ./...
```

## Module
The module path in `go.mod` is set to `clustership`. If you plan to host this on a remote (e.g., GitHub), you can update it to your repository path, for example:
```
module github.com/yourname/ClusterShip
```
